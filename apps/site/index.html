Show your photographs with the settings that made them.

Fovea opens a folder of RAW files and reads what the camera recorded for each one. Add a caption, present them fullscreen, and send the whole set to someone as one file. It runs on a Mac, on Windows, or in a browser, and it never uploads anything.

Download or open it in your browser

The camera data stays with the picture

Fovea reads NEF, CR2, CR3 and ARW files, as well as JPEG, TIFF and PNG. For every photograph it shows the body, lens, focal length, aperture, shutter speed and ISO. When the camera recorded a focus point, Fovea draws it on the frame.

Your original files are only read. Fovea never writes to them.

Write the story, then present it

Each photograph gets a caption: where you were, how long you waited, what happened next. Present the set fullscreen with a small overlay you control. Arrow keys and swipes move between frames.

Anyone you share with can leave comments on individual photographs.

One file to send

Export a project as a single .fovea file, with the photographs, captions and comments inside. It opens on a Mac, a Windows PC, or a phone's browser. There are no accounts and nothing is uploaded. Once it has loaded, it works offline.

Opening it the first time

The app isn't signed with an Apple Developer ID yet. Drag Fovea to Applications, then run this once in Terminal:

xattr -dr com.apple.quarantine "/Applications/Fovea.app"
